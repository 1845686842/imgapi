## ✨ 功能特性

### 🔑 多 API 密钥管理
- 添加或删除 API 密钥
- 一键重置密钥
- 快速复制 API 调用链接

### 🖼️ 图片批量管理
- 批量添加图片 URL（自动检测重复）
- 支持两种添加模式：
  - **仅添加未重复链接**
  - **强制添加**
- 批量删除，支持全选/反选
- 图片预览功能

### 🛡️ 智能检测系统
- **失效检测**：扫描无效图片链接
- **重复检测**：自动清理重复 URL
- 支持单张或批量删除异常图片

### 👨‍💻 管理员后台
- 修改管理员密码（强制强度校验）
- 安全退出登录
- 响应式操作界面

## 🚀 安装部署

### 步骤
1. 将项目文件上传至网站根目录（需将 `public` 设为根目录）
2. 访问域名，自动进入安装引导页面
3. 填写数据库信息：
   - 数据库主机
   - 数据库名称
   - 用户名和密码
4. 设置管理员账号（密码需 ≥8 位，包含字母和数字）
5. 安装完成后，删除 `public/install.php` 文件

## ❓ 常见问题 (FAQ)

### Q：出现 403 Forbidden 错误怎么办？
**解决方案**：
1. 确保 `public` 目录权限设置为 755
2. 确认服务器根目录正确指向 `/public` 文件夹

### Q：如何重新安装系统？
**步骤**：
1. 删除根目录下的 `config.php` 文件
2. 刷新浏览器页面
3. 系统将自动进入安装向导界面

### Q：API 链接返回无效响应？
**排查方法**：
1. 检查 API Key 是否输入正确

### Q：忘记密码怎么办？
**解决方案**：
1. 修改根目录下的 `config.php` 文件中的密码

## 📝 总结

在开发过程中，最初计划为每个图片链接添加缩略图，但考虑到以下问题，最终调整了方案：
1. **本地缓存方案问题**：如果将缩略图缓存到本地，大量图片会占用过多api服务器硬盘和宽带资源。
2. **源站调用方案问题**：直接调用源链接会导致每次打开后台时都重新从源站加载图片，会大量浪费api服务器宽带资源,建议还是文明获取。

**最终方案**：
- 以链接形式展示 API 图片链接，并为每个链接添加预览图按钮。
- 整个源码仅十几 KB，图片链接和 API 组均存储在数据库中。
- 后台鉴权逻辑位于根目录的 `config.php` 文件，忘记密码时可直接修改此文件。
